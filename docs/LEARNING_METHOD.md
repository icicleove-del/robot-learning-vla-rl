# 如何学习：先项目，后补基础

每次只选择一个真实工程问题，不安排与当前问题无关的大而全理论课程。

1. **进入上游项目**：明确机器人任务、真实输入输出及模型在系统中的作用。
2. **定位一个真实函数**：标记调用方/被调用方/输入 shape/输出 shape；当前无本地源码时使用官方固定标签页面阅读。
3. **记录真正不懂的知识**：例如 `nn.Module`、Attention、Flow Matching，只补能继续理解当前函数的范围。
4. **做最小验证**：Toy 实现要标记“概念验证”，与真实 SmolVLA 区分；必要时使用 Python 标准库/少量 Tensor。
5. **返回真实代码**：对照自己实现，找出 mask、batch、时间维、数值稳定性、错误处理等关键差异。
6. **留下可验证记录**：文件/函数链接、测试命令和实际输出；无实测则写未执行。

每天约 2.5 小时为建议上限：真实源码与代码操作为主，理论按需，最后简短复盘。另 1 小时面试/投递独立进行。

## 不等同于学会的情况
- “AI 帮我解释过/生成过” ≠ 我可以独立解释或调试。
- “运行了官方推理 demo” ≠ 我训练过模型。
- “改了超参数” ≠ 有原创算法贡献。
- “在仿真中成功” ≠ 真实机器人实机部署经验。
